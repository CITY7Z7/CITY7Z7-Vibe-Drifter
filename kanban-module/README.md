# Модуль «Kanban-оркестратор задач»

Эталонная реализация слоя оркестрации задач: декомпозиция целей в ориентированный ациклический граф зависимостей (DAG), параллельное исполнение с ограничением `maxParallel`, автоматический каскадный запуск последующих задач по цепочке и реактивный UI на React + SSE.

## Быстрый запуск

### 1. Запуск изолированного Демо
```bash
# Установка зависимостей (если ещё не установлены)
npm install

# Запуск dev-сервера с демо-приложением на порту 3000
npm run dev
```
После старта откройте в браузере: `http://localhost:3000`

### 2. Запуск тестов
```bash
# Запуск полного набора unit & integration тестов (Vitest)
npm test

# Запуск сквозного E2E тестирования (Playwright)
npm run test:e2e
```

## Структура модуля
- `src/core/` — чистая доменная логика без сторонних библиотек (DAG-граф, шедулер, парсер, шина событий);
- `src/storage/` — адаптеры хранения данных (`SQLiteStorageAdapter` на better-sqlite3 и `MemoryStorageAdapter`);
- `src/executors/` — исполнители задач (`mock`, `http`, безопасный `shell`);
- `src/planner/` — парсер текстовых инструкций и LLM-адаптер для декомпозиции целей;
- `src/server/` — Express Router (`createKanbanRouter`) с поддержкой SSE потока;
- `src/ui/` — скоупленный React-компонент `<KanbanBoard />` с переключением на интерактивный граф зависимостей (SVG) и боковым чатом;
- `src/templates/` — 19 эталонных шаблонов задач (Greenfield, Modernization, Testing, Features, DevOps);
- `MODULE.json` — манифест модуля и список функциональных возможностей;
- `INTEGRATION.md` — пошаговая инструкция по инъекции модуля в другой проект.
