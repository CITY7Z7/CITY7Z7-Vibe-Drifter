## 🎯 Рекомендуемые маршруты изучения (Reading Paths)

### Маршрут А: «Быстрый старт и запуск» (10 минут)
1. Прочтите [Главный README.md](../README.md) и запустите сервер (`npm run dev`).
2. Ознакомьтесь с [Дизайн-системой](./design-system.md), чтобы понимать интерактивные состояния карточек и колонок.
3. Изучите [Тестирование и Workflows](./workflows-and-testing.md) для проверки локальной среды (`npm test`).

### Маршрут Б: «Инженер интеграции: перенос в другой проект» (30 минут)
1. Прочтите [Руководство по интеграции](./integration-guide.md) — философия «Инъекция, а не черный ящик».
2. Изучите [Документацию модуля](./kanban-module.md) и [Спецификацию API](./api.md).
3. Посмотрите реализацию исполнителей (`TaskExecutor`) в [Архитектуре](./architecture.md).

### Маршрут В: «Senior Архитектор / Core Maintainer» (Полное погружение)
1. [Главный README](../README.md) → [docs/architecture.md](./architecture.md) → [docs/kanban-module.md](./kanban-module.md).
2. [docs/api.md](./api.md) → [docs/integration-guide.md](./integration-guide.md).
3. [docs/design-system.md](./design-system.md) → [docs/workflows-and-testing.md](./workflows-and-testing.md) → [docs/CHANGELOG.md](./CHANGELOG.md).
