## [v1.0.0] - 2026-10-01: Эталонный Full-Stack оркестратор

### 🚀 Главные нововведения (Major Highlights)
- **Готовая Full-Stack песочница:** Полная интеграция Express 4.21 + Vite 8.3 + React 19 + Better-SQLite3 в едином процессе на порту 3000 (`server.ts`).
- **Монолитная изоляция модуля:** Сформирован независимый пакет `kanban-module/` со строгими правилами изоляции (`kb-*`, `kanban_*`, `/api/kanban/*`), готовый к инъекции в любое стороннее приложение по спецификации `INTEGRATION.md`.
- **56 автоматизированных тестов:** 100% прохождение unit- и интеграционных тестов в Vitest + сквозные E2E сценарии в Playwright.
- **Двуязычная локализация:** Бесшовное переключение интерфейса между русским и английским языками (RU/EN) с сохранением состояния.
- **Интерактивный граф зависимостей:** Полноценный SVG-холст с динамическим расчетом сплайнов Безье, подсветкой предков/потомков и интерактивным зумом/панорамированием.

### 📦 Детализация по коммитам и слоям

#### Ядро и Алгоритмы (Core Layer)
- `commit 7fa810c`: Внедрен трехцветный алгоритм DFS детекции циклов в графе зависимостей (`validateGraphAcyclic`, `validateNewLink`).
- `commit 4d19b3a`: Реализован расчет топологических слоев графа (`computeGraphLayers`) для ярусного отображения узлов слева направо.
- `commit 9b207ef`: Разработан шедулер задач с поддержкой пула параллелизма `maxParallel`, приоритизации (`priority` DESC, `createdAt` ASC) и каскадного перевода зависимых карточек в статус `blocked` при сбое предка.
- `commit e318f21`: Реализован детерминированный парсер планов (`DeterministicPlanParser`) с поддержкой синтаксиса `[1] Title -> [2] Title` и маркера автостарта `start: 1, 2`.

#### Серверный слой и Транспорт (Backend & SSE)
- `commit 55c0291`: Разработана фабрика `createKanbanRouter` с полной схемотехникой Zod для досок, задач, связей и шаблонов.
- `commit 6a18d34`: Построен менеджер Server-Sent Events (`SSEManager`) с поддержкой Keep-Alive пингов каждые 15 секунд, автоматическим удалением оборванных соединений и фильтрацией событий по `boardId`.
- `commit 8b44910`: Реализована политика восстановления после сбоя сервера (`recoverPolicy`: `fail` или `requeue`) в методе `scheduler.recoverInterruptedTasks()`.

#### Хранилище данных (Storage Layer)
- `commit c72a390`: Написан `SQLiteStorageAdapter` на базе `better-sqlite3` с режимом WAL (`Write-Ahead Logging`), внешними ключами и каскадным удалением связей.
- `commit 194ee02`: Реализован `MemoryStorageAdapter` для юнит-тестирования в изолированной оперативной памяти.
- `commit f8913b7`: Создана встроенная коллекция из 19 готовых шаблонов задач (`starter.json`), разбитых по категориям (`greenfield`, `modernization`, `testing`, `features`, `devops`).

#### Пользовательский интерфейс (Frontend Layer)
- `commit 3e51082`: Разработан компонент `<KanbanBoard />` с 7 колонками жизненного цикла (`backlog`, `ready`, `in_progress`, `review`, `done`, `failed`, `blocked`).
- `commit 709ca88`: Реализована интерактивная подсветка родословной карточки: янтарная рамка для всех прямых и косвенных предков, бирюзовая — для потомков.
- `commit 42bc194`: Добавлен нативный HTML5 Drag & Drop с валидацией допустимых переходов конечного автомата (FSM).
- `commit a5492d1`: Создано модальное окно деталей задачи (`TaskDetailModal`) с просмотром терминального лога в реальном времени, вкладкой управления зависимостями и ручным аппрувом.
- `commit c9081e6`: Построен выдвижной чат-планировщик (`PlannerChat`) с предпросмотром плана перед его применением на доску.

## [v0.9.0] - 2026-09-28: Реактивный UI и интерактивный SVG-граф

### Added
- Компонент `<DependencyGraph />`:
  - Расчет позиционирования узлов по уровням глубины;
  - Отрисовка кривых связей Безье (`M x1 y1 C cx1 cy1, cx2 cy2, x2 y2`);
  - Визуальные маркеры стрелок с цветовой дифференциацией статуса источника;
  - Миникарта и зуммирование холста.
- Хук `useKanban`:
  - Автоматическое переподключение SSE с экспоненциальной задержкой;
  - Локальный стейт-кэш для мгновенного отклика UI без блокировок.

### Changed
- Переход на Tailwind CSS v4 с объявлением через `@import "tailwindcss";`.
- Изоляция всех стилей доски внутри корневого селектора `.kb-orchestrator-root`.

## [v0.8.0] - 2026-09-22: SSE-транспорт и Express Router

### Added
- Эндпоинт `GET /api/kanban/events` для потоковой передачи событий:
  - `task:created`, `task:updated`, `task:deleted`, `task:log`, `task:progress`;
  - `board:updated`, `board:paused`, `board:resumed`.
- Эндпоинты ручного управления жизненным циклом:
  - `POST /tasks/:id/run` — принудительный запуск карточки;
  - `POST /tasks/:id/cancel` — прерывание исполняемой задачи;
  - `POST /tasks/:id/retry` — повторная попытка с каскадной разблокировкой потомков;
  - `POST /tasks/:id/approve` / `POST /tasks/:id/reject` — шлюз ручного ревью.

### Security
- Валидация всех параметров маршрутов через `zod` с информативными текстами ошибок.
- Поддержка внешней авторизационной middleware через опцию `createKanbanRouter({ auth })`.

## [v0.5.0] - 2026-09-15: Хранилище SQLite и исполнители

### Added
- Пакет исполнителей `src/executors/`:
  - `MockExecutor`: настраиваемая задержка (`defaultDelayMs`), симуляция прогресса 0–100%, генерация тестовых артефактов;
  - `HttpExecutor`: выполнение внешних веб-хуков и REST-запросов (GET, POST, PUT) с подстановкой результатов зависимостей;
  - `ShellExecutor`: запуск терминальных команд с жестким белым списком разрешенных утилит и таймаутами.
- Реестр исполнителей `ExecutorRegistry` для динамической регистрации кастомных воркеров.

## [v0.3.0] - 2026-09-08: Планировщик и шаблоны

### Added
- Доменный модуль `src/planner/`:
  - `DeterministicPlanParser`: разбор многострочных сценариев на русском и английском языках;
  - `GeminiPlannerAdapter`: трансляция неструктурированной цели пользователя в граф задач через `@google/genai`;
  - `starter.json`: 19 преднастроенных графов задач для веб-разработки, тестирования, рефакторинга и развертывания.

## [v0.1.0] - 2026-09-01: Математическое ядро (DAG и шедулер)

### Added
- Доменные типы в `src/core/types.ts`:
  - Модели `Task`, `Board`, `TaskStatus`, `TaskExecutor`, `PlanPreview`.
- Алгоритмы графов в `src/core/graph.ts`:
  - Поиск циклов через DFS с раскраской вершин;
  - Топологическая сортировка;
  - Валидация разрешенных переходов FSM (`validateManualTransition`).
- Диспетчер выполнения в `src/core/scheduler.ts`:
  - Асинхронный цикл обработки очереди;
  - Управление лимитом `maxParallel`;
  - Механизм передачи контекста между зависимыми задачами.
